# 📊 Sales Analysis Dashboard — Power BI

An interactive **Sales Analysis Dashboard** built using **Microsoft Power BI** to transform sales data into clear and meaningful visual insights. The dashboard uses KPI cards, charts, graphs, slicers, and filters to help analyze sales performance across different categories, segments, regions, and time periods.

## 📌 Project Overview

The goal of this project is to demonstrate how raw sales data can be transformed into an interactive dashboard that makes business performance easier to understand.

The dashboard provides a visual overview of important sales metrics and allows users to explore the data interactively using slicers and filters.

## 🎯 Objectives

* Analyze overall sales and profit performance
* Compare sales across different product categories
* Analyze regional sales performance
* Understand sales trends over time
* Identify important sales patterns through visualizations
* Create an interactive and user-friendly Power BI dashboard

## 🛠️ Tools & Technologies

* **Microsoft Power BI** — Dashboard development and data visualization
* **Power Query** — Data cleaning and transformation
* **Excel/CSV Dataset** — Source data

## 🔄 Data Preparation

The data was prepared in Power BI using Power Query.

The preparation process included:

* Importing the sales dataset
* Reviewing and cleaning the data
* Transforming data where required
* Preparing fields for analysis
* Creating a dataset suitable for dashboard visualization

## 📊 Dashboard Features

### KPI Cards

Provides a quick overview of important metrics such as:

* Total Sales
* Total Profit

### Sales Analysis

* Sales comparison across categories
* Sales comparison across segments
* Sales performance by region

### Trend Analysis

A time-based visualization is used to understand how sales performance changes over time.

### Category Analysis

Visualizations help compare the performance of different product categories.

### Regional Analysis

The dashboard provides a view of sales performance across different regions.

### Interactive Filters

Users can interact with the dashboard using slicers and filters to analyze specific parts of the dataset.
